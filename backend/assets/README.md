# Certificate artwork (optional)

Drop these files here and the certificate PDF will use them automatically:

- `certificate-logo.png`       - the round SelahTech Academy emblem (square PNG, transparent background, 600x600 or larger)
- `certificate-signature.png`  - the Program Manager's signature (PNG with transparent background)

If a file is missing, the certificate still renders (a simple drawn emblem, and a blank signature line).
